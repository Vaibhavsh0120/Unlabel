# Insight artwork

Twenty individually generated illustrations for the twenty insight articles.
Each article owns its own lossless WebP: no duplicated image, reused crop or recolor.
Subjects follow the user's desktop/mobile green botanical references; artwork
does not embed article copy, numbers, branding or factual nutrition claims.

Generated on 9 October 2026 with the built-in `image_gen.imagegen` tool and
`transparent_background: true`. The references were inspected as visual style
references, not edit targets. No provider key, API billing or fallback CLI was
used. Original generated images remain in Codex's generated-images directory.

Every original delivered PNG was 512 by 512 pixels in RGBA. The entire original canvas
was resampled with Lanczos to fit within 460 by 460 pixels and centered on a
transparent 512-square canvas. This preserves the generator's alpha, complete
objects and shadows while providing at least 26 pixels of transparent padding.
There is no manual background removal, alpha threshold, silhouette crop or
object replacement. Display the illustration with contain fit on the card's
own theme surface. On 12 October 2026 the app assets were converted to lossless
WebP with identical dimensions and decoded RGBA pixels, including transparency.
The [optimization manifest](../optimized-assets.json) records current runtime
hashes and the original source revision. Generation hashes below remain original
PNG provenance; those files are recoverable from Git history.

`generation-manifest.json` records the exact prompt, source filename and hash,
delivered hash, dimensions, byte count and alpha bounds for every article ID.
All twenty delivered SHA-256 hashes are distinct. These are decorative
illustrations; they are not packaging evidence or proof of nutritional
composition.

# Solar linear icons

Seventeen original Solar SVGs by **480 Design**, obtained through Better Design's
Iconify-backed installer on 7 October 2026. Original paths are unchanged;
the app applies theme colors and scaling at render time.

The bell icon was added through the same installer on 8 October 2026.

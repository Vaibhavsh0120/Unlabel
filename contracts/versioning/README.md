# Compatibility metadata

Reserve the shared API-major/contract-schema definitions and release-manifest schemas here. The Flutter starter declares `0.0.0+1` in `frontend/pubspec.yaml`. The manual release workflow injects the selected product version, build number and source commit into both mobile artifacts and records them in `build-manifest.json`.

Local backend **v0.4.0** preserves API major 1, contract schema 1, product adapter 1 and the strict product/catalogue identity v1 responses. Nutrition lookup and confirmed-row normalization retain their separate contracts and version metadata. Catalogue status/identity and the separate rich-facts response use a validated read-only SQLite snapshot; hosted activation also requires a verified build receipt. The `catalogue_facts` capability requires a facts-enabled store, while an older identity-only store remains readable without enabling facts. Live OFF product/nutrition reads remain separate from snapshot lookup.

Snapshot metadata records source format, export/index dates, hash, counts and coverage state. The current JSONL snapshot has **24,641 supported records**, with direct nutrition availability, canonical tag availability, record dates and attributed official image URL descriptors in its separate facts contract. An imported India-tagged source is not proof of every product sold in India or current package facts. Historical v0.1.0 through v0.3.0 OpenAPI files remain release records. Valid loaded claim knowledge reports `claims-2026-10-06.1` and enables the separate `claim_checks` capability. A verified bundle exposes its two-file `knowledge_artifact` receipt summary; direct canonical local loading has no artifact receipt. Broader nutrition analysis, ingredient explanations, comparison and AI remain disabled. Confirmed claim assessments retain their selected table/context, input references, numerical-only scope and claim-specific statutory conversion metadata; normalization-v1 remains unchanged. Frontend stays **0.0.0+1**, and its APK/unsigned IPA artifacts are unchanged.

# Teammate handoff

> Unlabel's foundation is ready: one Flutter project directly in frontend for Android/iOS/web, a responsive light/dark starter, a manual APK/unsigned-IPA workflow, and complete architecture/data/source/release docs. Python/FastAPI is selected for the later shared Vercel backend. Core scanning and food analysis are not implemented yet.

## What exists

- Flutter/native/web scaffold, appearance selection, lockfile and layout/theme/large-text tests.
- Reserved backend, knowledge, contracts, fixtures, design and optional AI folders.
- Data/API/offline/deployment/release plans and checked provider/source research.
- Manual build/checksum/manifest/release workflow and v0.0.0 app version.

No OCR plugin, rule engine, source corpus, backend endpoint, Vercel deployment, trained model or secret has been added. Actual CI/release status must come from the workflow result.

| Topic | Direction |
| --- | --- |
| Frontend | Single Flutter app directly frontend; Android/iOS/web |
| UI | iPhone/iPad orientations/MacBook; light/dark; palette undecided |
| Backend | Python/FastAPI, separate future Vercel project |
| Evidence | Confirmed package first; reviewed FSSAI/public sources for criteria |
| Offline | Supported bundles; missing coverage remains uncertain |
| Rules | One canonical source with Dart/Python parity fixtures |
| AI | Optional wording; training/HF only if separately useful/eligible |
| Storage | Device/browser local history/preferences; server stateless |
| Releases | Same commit/version/build; unsigned IPA is not installable |

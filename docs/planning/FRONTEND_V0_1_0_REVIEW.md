# Frontend v0.1.0 — Connected Label Reader

Source/web release, independently versioned from backend v0.6.0. Native packages were not rebuilt.

## Delivered

Manual barcode lookup, bounded name/brand discovery, current-label entry with explicit confirmations, sourced current/historical reports, private device bookmarks/history, and persisted appearance. Light is the first-use default. No personal report data is uploaded by this version. Automatic structured public product observations retain the backend's separate storage outcomes.

The new leaf and Unlabel wordmark have light/dark masters and Android/iOS/web assets. The authored Nunito wordmark is outlined; runtime icons need no font dependency. The generator verifies 42 assets/font/license files using standard Python in normal builds.

# Community Product Catalogue implementation plan

**Updated 7 October 2026:** implementation resumed on the user's instruction.
The automatic-saving design is implemented, pushed, hosted-verified and released. Exact command/proof status belongs in the
[review](../../planning/BACKEND_V0_4_0_REVIEW.md), not inferred from this checklist.

**Goal:** Save structured public package observations automatically, deduplicate
facts and serve qualified exact product fields with source provenance.

**Design:** [Final v0.4.0 design](../specs/2026-10-07-community-catalogue-design.md).
**Whole product:** [Master plan](../../planning/MASTER_PLAN.md).

## Constraints

- ₹0/no card/no linked billing; no paid fallback, Storage/Functions/TTL/backups/PITR.
- One backend version at a time; preserve Flutter 0.0.0+1 and historical releases.
- Structured public facts only; photos/raw OCR/profiles/history remain private.
- No separate Share flag, custom training or AI requirement.
- Preserve OFF licenses, originals, confirmed-label claims and unknown evidence.

## 1. Contracts, normalization and resolution

- [x] Implement/test strict provisional/confirmed intake, optional barcode,
  front/back/pairing, origin/license, privacy and numeric bounds.
- [x] Compute full observation and semantic factual hashes; normalize on server.
- [x] Resolve typed fields with lineage, dates, alternatives and source groups.
- [x] Preserve unknown/zero, conflicts, incompatible bases/preparation/revisions;
  prohibit generic branded-packet imputation and automatic trust escalation.

## 2. Durable storage and authentication

- [x] Implement/test immutable receipts, semantic duplicate reuse, concurrency,
  quota, staging expiry, qualified candidates and moderator review/supersession.
- [x] Verify anonymous tokens/project/expiry/revocation and keyed ownership hashes.
- [x] Use explicit credentials and bounded network calls; no ambient fallback.
- [x] Exercise emulator transaction/retry boundaries; exact results in review.

- [x] Export v0.4.0 OpenAPI, five new schemas and six new synthetic examples.

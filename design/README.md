# Shared Unlabel design direction

The user selected the supplied white/forest/mint references and later supplied
matching dark examples. The Flutter implementation uses light off-white surfaces,
forest text/actions, mint icon backgrounds, rounded cards and generous spacing.
Dark uses near-black/charcoal surfaces, pale text, mint accents and restrained
borders. Light is the first-use default; an explicit saved choice persists locally.

[Interface contract](../DESIGN.md) records the real Material 3 adaptation, local
Solar icon attribution and evidence/accessibility limits. The generated React
registry does not replace this Flutter app. [Reference brief](references/README.md)
contains the original supplied examples; their product facts, scores and verdicts
are illustrative rather than approved fixture data.

Authored light/dark app icons and generated platform resources live in
[frontend/assets/brand](../frontend/assets/brand/README.md). Upcoming decorative
art should be cute and warm; generated packets must not impersonate an actual
scanned product or its facts. The [next screen plan](../docs/planning/ACCOUNT_SYNC_SCREEN_PLAN.md)
includes first-launch Welcome, optional login and all working screen destinations.

Reserved token/assets folders are not claims of implemented features. Review each
screen in light/dark and at mobile/tablet/desktop widths, large text and keyboard
navigation. Native icon/device switching remains separate from source validation.
